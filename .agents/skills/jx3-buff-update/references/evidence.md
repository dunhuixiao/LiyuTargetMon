# 证据与数据源

在分析技改、查询数据库或确认截图映射时读取。以下是来源入口及历史案例，不承诺数据已更新到用户指定版本。

## 来源入口

- 官方旗舰版公告：`https://jx3.xoyo.com/`。按资料片名、门派和用户指定日期检索，确认公告标题、发布日期、旗舰端正文以及后续修订。若页面同时含移动端或绝境战场，提取前先划定栏目边界。
- Buff 数据库已用入口：`https://node.jx3box.com/resource/std/buff/list?id=34737&per=100`。将示例 ID 替换为待查数字，核实实际返回结构、等级、效果与图标；该地址的可用性和最新程度需现场验证。
- 奇穴快照入口：`https://github.com/JX3BOX/jx3box-talent/tree/master/output/std`。先查看可用版本文件，再选取目标版本前后快照；不要长期固定使用某个历史文件。
- 本次流程参考过的历史官方公告：`https://jx3.xoyo.com/show-2466-7561-1.html`。
- 本次流程比较过的历史快照：`https://raw.githubusercontent.com/JX3BOX/jx3box-talent/master/output/std/v20260524.json` 与 `https://raw.githubusercontent.com/JX3BOX/jx3box-talent/master/output/std/v20261030.json`。这些仅是历史对照，不是未来请求的“最新”。

优先原始公告、数据库原始记录、版本快照和用户提供的游戏调试图。转载可用于发现线索，但不要用缺少版本信息的转载替代核验。

## 如何判断证据

| 材料 | 可以确认 | 不能单独确认 |
| --- | --- | --- |
| 正式公告／前后奇穴快照 | 技能和奇穴效果、增删与触发条件变化 | 具体运行时 BuffID／IconID |
| 数据库记录 | 该快照里的 ID、等级、图标、名称与效果 | 它已覆盖最新补丁、当前所有触发来源 |
| 当前游戏调试截图 | 图中实际状态的 ID、Level、IconID 和可见效果 | 未显示的奇穴来源、完整总持续时间、所有等级 |
| 现有监控配置 | 用户正在使用的分类、颜色、显示文字与旧 ID | 该 ID 仍可在新版本触发或已被官方废弃 |

将来源确认与 ID 确认分开。例如公告已确认“招式命中添加某状态”，但只找到旧数据库同名条目时，应写“新触发已确认，运行时 ID 待核”，不要写“新版本使用此 ID 已确认”。

## 研究结果的最小记录

通过心法范围及 PvP 适用性筛选的候选记录以下信息。默认过滤 T 心法专属效果，用户可见清单、补漏及待截图项目采用已过滤的候选集合。共享状态按可触发的非T或通用来源记录。

- 记录门派、心法、来源类型与触发链，并填写适用的触发技能、秘籍名称、奇穴名称及重数或“混选奇穴”类别。重数按对应版本核对，已移除来源使用有依据的旧版重数。
- 效果作用对象、触发对象及对侠士有效的分支。同一技能含不同目标分支时，明确本次纳入的 PvP 或通用部分。
- 前后变化和适用日期／版本。
- BuffID、Level、IconID、正负面、效果文字及当前配置位置；不明项显式标记未知。
- 对增伤候选先记录强化范围和分类依据，特定强化还需记录实际监控用途。对减伤、通用爆发、化解候选记录单层效果百分比、最大层数、叠加规则、可达到的有效总数值及新增筛选结果，按 [配置格式与仓库规则](configuration.md) 判断分类与阈值。
- 来源 URL 或截图路径、查询／截图上下文，以及哪些结论已确认。待截图项目另记复现条件、操作步骤、观察对象与时机、简要效果和具体缺失字段。
- 处置：确定新增、确定修改、确定删除、保留、待核；指定字段改动及原因。

用户只要确定的增删改时，主清单只展示可执行项。其他记录保存在临时分析资料中，必要时用一句说明缺少什么证据。

## 来源类型与效果清单格式

按状态的直接来源选择类型，心法列单独展示所属心法。

| 来源类型 | 判定与展示要求 |
| --- | --- |
| 心法自带 | 心法被动或心法固有机制直接提供的状态，写出对应机制和触发条件 |
| 技能本体 | 基础招式直接提供的状态，写明招式及必要的施展、命中或资源条件，例如“【技能本体】酒中仙 → 昊破” |
| 秘籍 | 装备特定秘籍后才产生的效果，写明关联招式及秘籍全名，名称未核实时标注“秘籍名称待核” |
| 奇穴 | 主动奇穴产生的状态，或被动奇穴修饰招式后产生的效果，写明主动／修饰关系，并在效果栏注明奇穴重数与必要核心前置 |

基础与修饰分支分别说明。例如断江流的基础免控来自技能本体，混选「流形」修饰后减伤数值提高。根据证据记录二者的状态 ID 和等级关系。其他来源如装备特效，按实际机制命名来源类型。来源不明时明确写“来源待核”。

使用三列“心法｜技能／奇穴来源｜需要监控的效果”。来源列包含类型标签及具体名称或触发链。奇穴修饰的名称、重数和核心前置写在第三列，与对应效果放在一起。秘籍全名放在第三列或同条紧随的说明中。

以下示例取自本次会话，实际使用时按目标版本核对效果。

| 心法 | 技能／奇穴来源 | 需要监控的效果 |
| --- | --- | --- |
| 通用 | 【技能本体】水榭花盈 | 成功施展后 **80%减伤，3秒** |
| 云裳 | 【技能本体＋奇穴修饰】风袖低昂 | **50%伤害化解，13秒**，第二重「拂罗」修饰后65%，被驱散回复20%最大气血 |
| 云裳 | 【奇穴修饰】秋月 → 王母挥袂 | 给目标 **25%减伤，4秒**，由第一重「秋月」提供 |
| 云裳 | 【奇穴修饰】传芳 → 繁音急节 | **90秒治疗传递标记**，触发10次后转移，最多传递3次，由混选奇穴「传芳」提供 |
| 笑尘 | 【技能本体】酒中仙 → 昊破 | 自身通用属性强化，持续70秒，施展酒中仙或进入逍遥状态时获得 |
| 笑尘 | 【秘籍】恶狗拦路 | 命中目标后 **减速40%，5秒**，来自《打狗棒法·恶狗拦路》人偶图残页 |

## 待截图清单与复现路径

待截图清单使用“心法｜状态／来源｜复现路径｜Buff 简要效果｜待核字段”，使用户能按步骤触发并找到需要截图的状态。

- 复现路径写出影响触发的必要条件，包括心法、奇穴名称与重数、核心前置、秘籍、资源或姿态，以及目标类型。按实际操作顺序说明施展什么技能、是否需要命中、二段或结束触发，最后指出观察自身或目标的状态栏及截图时机。
- 侠士限定效果使用可触发该效果的切磋或敌对侠士目标。根据证据选择目标类型，资料缺失的复现环节标注待核，提供已有依据的步骤。
- 简要效果写明控制类型或增减益、数值、已核总持续时间和必要叠层信息。已知值与待核值分别标识，来源采用对应版本的证据。
- 待核字段具体到 `ID`、`Level`、`IconID`、可见效果或叠层能力，以当前证据的实际缺口为准。基础版、秘籍版或奇穴版在效果、等级或来源对应关系需要区分时分列复现分支，并说明预期差异。同效状态的多个触发入口可作为任选路径，优先提供步骤完整、容易复现的一条。
- 收到截图或用户调试文本后，将已确认的分支转入已核结果，后续清单列出剩余缺失项。已有截图覆盖的 ID、等级与图标直接复用，更新对应来源及配置处理结论。

## 本次纯阳案例带来的判定规则

- 奇穴表中的“长生”“无我”“妄心”在被比较的前后快照里描述相同，所以不能因为出现在新版表中就称其为新增或修改。
- “转乾坤”回血调整不证明其免控分支也被修改；同技能的多个状态分别判断。
- 旧“物我两忘”退场不单独证明三个无衰减控制 ID 全部废弃；需确认各 ID 的施加链和继承来源。
- 用户指定删除“合真”是配置决定，不应记为官方已证实废弃的状态。

以上为证据判断示例，不构成未来版本的固定增删清单。
